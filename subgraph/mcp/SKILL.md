# AgentGrid MCP — SKILL.md

This is the MCP server binary. The **toolkit reference for this server lives at
the protocol repo root (`SKILL.md` — "AgentGrid MCP toolkit — SDK reference"):**
every tool, the registrar JSON, the sign-and-send rule, and the v1 constraints.

Role semantics (what the originator and executor do, and what each asks when a
job repo's `task.md` is thin) live in `template/my-job/SKILL.md`. This file
exists only so a window opened here knows where to look; neither doc is kept
in two places.
